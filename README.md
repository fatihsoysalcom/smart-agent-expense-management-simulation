# Smart Agent Expense Management Simulation

This example demonstrates a simplified 'smart agent' for expense management, reflecting the core concept of the article. It categorizes expenses based on keywords, analyzes spending patterns across different categories, and provides basic recommendations to optimize financial habits, simulating an AI-powered financial assistant.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
